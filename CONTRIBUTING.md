# Contributing

Thanks for your interest in improving this project.

## Workflow

1. Fork the repository and create a feature branch.
2. Make your changes and test them.
3. Commit with a descriptive message.
4. Push to your fork and open a pull request.

## Code style

- **Python:** follow PEP 8, use meaningful variable names, add docstrings to functions, and keep functions small and focused.
- **Notebooks:** use markdown cells for explanation, keep code cells focused, use clear section headers, and keep output cells visible.

## Before submitting

- Run each notebook top to bottom without errors.
- Check that plots render and results are reproducible (fixed random seeds).
- Install dependencies with `pip install -r requirements.txt` (versions are pinned deliberately).
